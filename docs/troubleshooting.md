# Troubleshooting

| Symptom                                                                                    | Cause                                                                                                                     | Fix                                                                                                                                                  |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| No **Edit on page** button in the admin                                                    | Plugin not registered, the collection isn't listed, or the user can't update the document                                 | Check `onpage({ collections })`; the button hides without update permission. Regenerate the import map (`payload generate:importmap`).               |
| "Edit on page" opens the page but there's no dock                                          | `<OnPage />` not mounted, or not inside the frontend layout                                                               | Mount it in the frontend root layout ([getting started](getting-started.md#3-mount-the-editor)).                                                     |
| Dock shows "Nothing editable on this page"                                                 | Reads don't pass `onpageContext()`, and nothing is annotated                                                              | Spread `...(await onpageContext())` into the draft reads that feed the page.                                                                         |
| The dock covers your site's own fixed bottom bar (cart, cookie banner)                     | The dock sits 16px from the bottom by default                                                                             | Raise it with the `--po-dock-bottom` CSS variable, e.g. `html:has(.cart-bar) { --po-dock-bottom: 88px }`. The preview toolbar and notices follow it. |
| Text isn't clickable but other text is                                                     | The string is changed before rendering (truncated, split into words), used in an attribute, or it's a machine-named field | Render the raw value, or annotate the element (`e.field(path)`). See [auto-mapping caveats](concepts/auto-mapping.md#caveats).                       |
| A comparison like `title === 'Home'` fails in edit mode, or in-page anchors break          | Markers are appended to strings                                                                                           | Compare, slugify or measure `stegaClean(title)`. The full list is in [auto-mapping caveats](concepts/auto-mapping.md#caveats).                       |
| Share link shows published content                                                         | No proxy, a different secret in the proxy, or the matcher excludes the page                                               | Add `createOnPageProxy({ secret: process.env.PAYLOAD_SECRET })` with the same secret as Payload; check `config.matcher`.                             |
| Redirects or links point to the wrong host                                                 | `serverURL` unset behind a proxy                                                                                          | Set `serverURL` in the Payload config.                                                                                                               |
| "Changed by someone else"                                                                  | Another editor (or the admin) saved the document after you loaded it                                                      | **Keep my changes** (re-applies yours on their version) or **Reload latest** (drops yours). See [several editors](guides/collaboration.md).          |
| "… is editing this" in the dock; saves fail with "locked"                                  | Someone holds Payload's document lock (in the admin, or on the page)                                                      | Wait until they leave, or until the lock expires (5 minutes without activity).                                                                       |
| Editing ends after signing out in another tab                                              | By design: edit mode is bound to the auth cookie                                                                          | Sign in again and press **Edit on page**.                                                                                                            |
| Two Lexical copies / rich-text errors                                                      | Lexical version differs from Payload's                                                                                    | Install the Lexical version Payload's `@payloadcms/richtext-lexical` uses (`~0.50.0` for Payload 3.90).                                              |
| The editor never appears; the console shows "useOnPage must be used inside <OnPageEditor>" | Two copies of `@payload-onpage/react` installed                                                                           | Dedupe (`npm ls @payload-onpage/react`). The hub is shared across copies, but contexts aren't.                                                       |
| 403 "Cross-site request refused" from enter/exit                                           | A link or form posts from another origin                                                                                  | Use the built-in buttons; enter/mode/exit accept same-origin POSTs only.                                                                             |
| Next 15 build: `Cannot find module 'libsql'` (SQLite adapter)                              | Next 15 treats `libsql` as an external server package; with nested installs (Bun, pnpm) it isn't resolvable from the app  | Add `libsql` as a direct dependency of the app (the example does).                                                                                   |
