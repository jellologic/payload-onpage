# Security

## Reporting

Please report vulnerabilities privately through GitHub's **Report a vulnerability** (Security tab), not in public issues. We aim to acknowledge within 3 working days and to fix critical issues within 14 days, coordinating disclosure with you.

## Supported versions

| Version | Supported                                                     |
| ------- | ------------------------------------------------------------- |
| 0.2.x   | ✅                                                            |
| < 0.2   | ❌ (0.1 preview links could unlock drafts site-wide; upgrade) |

## Design

The threat model, access rules, cookies, preview-link design and CSRF protections are documented in [docs/concepts/security.md](docs/concepts/security.md).
