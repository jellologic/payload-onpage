# @payload-onpage/core

payload-onpage core: document refs, schema, field operations, stega codec, autosave and the editor session, plus the port interfaces adapters implement.

Part of [**payload-onpage**](https://github.com/jellologic/payload-onpage): on-page editing and draft previews for Payload CMS + Next.js. Setup, ports and security are in the [guide](https://github.com/jellologic/payload-onpage#readme).
